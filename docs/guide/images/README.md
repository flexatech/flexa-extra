## Conventions

- **Format:** PNG (or WebP if you prefer; then update the `.png` references).
- **Width:** aim for ~1400px wide for admin screens so text stays crisp.
- **Crop tight** to the relevant UI; avoid capturing the whole browser chrome.
- Keep the file names exactly as above so the guide links resolve without edits.
